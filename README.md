# 🎁 Game Items Hub

Красивый и удобный каталог игровых предметов, скинов, валюты и подарков.

## Как работает

1. **Выбери платформу** — ПК, приставка, телефон, планшет, мини-приставка  
2. **Выбери игру** — Brawl Stars, GTA 5, Roblox, Among Us, Minecraft, Fortnite, Valorant и другие  
3. **Выбери приз** — или найди через поиск  
4. Получи **официальную ссылку** на реальный магазин / страницу покупки

Все ссылки ведут только в официальные магазины издателей (Rockstar, Supercell, Epic, Roblox, Steam и т.д.).  
Сайт **не продаёт** и **не генерирует** коды — это удобный каталог реальных ссылок.

## Демо (GitHub Pages)

**https://superyaroslav8-arch.github.io/game-items-hub/**

(Включи GitHub Pages в Settings → Pages → Source: Deploy from a branch → main / root)

## Технологии

- Чистый HTML + CSS + JavaScript  
- Адаптивный дизайн  
- Тёмная тема с градиентами  
- Поиск по призам  

## Запуск локально

Просто открой `index.html` в браузере.
